# 🌿 饥荒地皮规划器

一个在线的《饥荒》地皮与建家点位规划工具。

👉 **直接在线使用：** [点击这里打开网页](https://feifei1313.github.io/dont-starve-planner/)

## ✨ 功能特点

- 🟩 **地皮涂色**：多种颜色自由填充，支持 30×30 到 300×300 多档尺寸，规划建家布局。
- 📍 **建筑点位**：支持放置龙鳞火炉、冰眼结晶器、雪球发射器、避雷针，实时显示作用半径。
- 📝 **文字标注**：点选任意格子添加文字说明（如"厨房"、"牛场"），文字颜色和大小可全局调整。
- 📏 **精确半径**：已按照游戏内单位精确换算成地皮格子数（游戏单位 ÷ 4），和游戏里完全一致。
- 🖱️ **顺手操作**：支持拖拽画布、滚轮缩放、撤销重做。
- 💾 **本地保存**：数据自动保存在浏览器，支持一键导出 PNG 规划图，建家时可对照查看。
