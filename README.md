# 🌿 饥荒地皮规划器

一个在线的《饥荒》地皮与建家点位规划工具。

👉 **直接在线使用：** [点击这里打开网页](https://feifei1313.github.io/dont-starve-planner/)

## 功能特点
- 🟩 **地皮涂色**：100×100 超大网格，多种颜色自由填充，规划建家布局。
- 📍 **建筑点位**：支持放置龙鳞火炉、冰眼结晶器、雪球发射器、避雷针。
- 📏 **精确半径**：已按照游戏内单位精确换算成地皮格子数（游戏单位 ÷ 4）。
- 🖱️ **顺手操作**：支持拖拽画布、滚轮缩放、撤销重做。
- 💾 **本地保存**：数据自动保存在浏览器，支持导出 PNG 规划图。
